# Calculadora feliz

Aplicación Android educativa con suma, resta, multiplicación, división y números decimales.

## Abrir el proyecto

1. Instala Android Studio desde https://developer.android.com/studio.
2. Abre Android Studio y selecciona **Open**.
3. Elige la carpeta `app basica prueba`.
4. Espera a que termine la sincronización de Gradle. Si solicita instalar Android SDK 35, acepta.

## Probar en un teléfono Android

1. En el teléfono abre **Ajustes > Acerca del teléfono**.
2. Toca siete veces **Número de compilación** para activar las opciones de desarrollador.
3. En **Opciones de desarrollador**, activa **Depuración USB**.
4. Conecta el teléfono por USB y acepta el mensaje de autorización que aparece en él.
5. En Android Studio, selecciona el teléfono en la barra superior y pulsa el botón verde **Run ▶**.

También puedes usar el emulador de Android Studio mediante **Device Manager > Add a new device**.

## Dónde modificar

- Interfaz: `app/src/main/res/layout/activity_main.xml`
- Colores: `app/src/main/res/values/colors.xml`
- Textos: `app/src/main/res/values/strings.xml`
- Cálculos: `app/src/main/java/com/ejemplo/calculadorainfantil/MainActivity.java`
